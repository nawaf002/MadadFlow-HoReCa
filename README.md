# MADAD Flow — HoReCa Command Center v2

A frontend-only Vue 3 + Vite + Tailwind CSS portfolio concept for HoReCa procurement operations.

## Included Features

- Procurement Health Center
- Smart Reorder Engine
- Supplier Comparison and Scorecards
- Delivery Command Center
- Product Availability Watchlist + Notifications
- Unified Finance / Invoice Panel
- Multi-location Demand
- Exception Center
- Food-cost and Waste Intelligence
- Interactive Purchase Order Creation, Cancellation, and Delivery Progression
- localStorage persistence for Orders, Inventory, and Suppliers

## Run the Project

Make sure Node.js is installed on your computer, then open the MADAD Flow project folder in Visual Studio Code. Open the VS Code terminal by selecting **Terminal → New Terminal** and make sure the terminal is inside the project folder. The first time you run the project, enter:

```bash
npm install
npm run dev

If Node.js or npm is not recognized, check that Node.js is installed correctly by running:

node -v
npm -v

To open the website, either hold Ctrl and click the localhost link directly in the VS Code terminal, or copy the link and paste it into Google Chrome, Microsoft Edge, or another browser.

Enjoy ;)
